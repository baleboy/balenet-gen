03. Implementation Sample

Here is the initialization logic for the Balenet Stream Listener. Notice the lack of overhead in the registration phase. 

// Initializing the Balenet Core Listener
const listener = balenet.createStream({
    id: "STREAM_ALPHA",
    buffer: 1024,
    mode: "reactive"
});

listener.on("data", (packet) => {
    // Hardware accelerated processing
    process.accelerate(packet.payload);
    console.log(`[SYS] Packet processed: ${packet.hash}`);
});
